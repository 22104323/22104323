I'm based in the Philippines (UTC+8) and open to remote or hybrid work. Reach me at work.jumaoasjames@gmail.com.

I publish these projects through [Daryll's Beehive](https://github.com/buildsbydaryll).

- [server-hardening](https://github.com/buildsbydaryll/server-hardening): one Ansible playbook locks down a fresh Ubuntu or Debian VPS, and a second checks every change without modifying the server. I tested both on a throwaway VM.
- [case-studies](https://github.com/buildsbydaryll/case-studies): two problems from client work. One is a Django contact form's rate limit, tested with six concurrent requests. The other is a staging deploy with no new inbound ports, where the server pulls its own updates.
- [reliability-labs](https://github.com/buildsbydaryll/reliability-labs): runnable labs that show a backend defect with a failing test, then fix it. The first is a FastAPI booking adapter that double-booked when the provider timed out.

I also worked on [callguard](https://github.com/ReidoBoss/callguard), a hackathon MVP for call-center quality checks that keeps call data on local hardware using Gemma model locally to turn call audio into transcripts.
